# AI Website Factory

An AI-first operating system for planning, designing, documenting and building high-quality websites with minimal manual work.

## The promise

You provide a short business brief. The system turns it into:

- business and audience strategy
- website blueprint and sitemap
- brand system
- design system
- content structure
- feature requirements
- development tasks

## Core workflow

```
Business Brief
  → Research
  → Strategy
  → Website Blueprint
  → Brand System
  → Design System
  → Content
  → Features
  → Build & QA
```

## Repository structure

- `docs/` — reusable master documents
- `templates/` — industry-specific starter templates
- `examples/` — completed example projects
- `agents/` — instructions for AI coding agents

## Quick start

1. Copy `templates/project-brief.md`.
2. Fill the minimum business information.
3. Create or update the project documents using the files in `docs/`.
4. Ask your AI coding agent to read the project documents before implementation.

## Core documents

| File | Purpose |
|---|---|
| PROJECT.md | business, goals and audience |
| WEBSITE-BLUEPRINT.md | sitemap, page architecture and user journey |
| BRAND.md | positioning, voice and messaging |
| DESIGN.md | visual and UX source of truth |
| CONTENT.md | page content source of truth |
| FEATURES.md | functional requirements |
| TASKS.md | delivery roadmap |

## Principle

**Minimal user input. Maximum AI execution.**

The AI should not ask the user to perform work that it can safely perform itself.
