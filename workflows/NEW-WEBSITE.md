# New Website Command

Use this command:

> New Website: [Business Name]

Then provide, if known:

- What the business does
- Location/market
- Target customer
- Main website goal
- Preferred style
- Existing website/social links

## AI execution sequence
1. Gather only critical missing information.
2. Research when useful and permitted.
3. Create PROJECT.md.
4. Create WEBSITE-BLUEPRINT.md.
5. Create BRAND.md.
6. Create DESIGN.md.
7. Create CONTENT.md.
8. Create FEATURES.md.
9. Create TASKS.md.
10. Build or hand off implementation instructions.

**Principle: minimal user work, maximum AI execution.**
