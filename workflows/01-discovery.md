# Workflow 01 — Discovery

## Input
A short AI Website Brief.

## Actions
1. Understand the business model.
2. Identify primary and secondary audiences.
3. Map audience problems and desired outcomes.
4. Identify competitors or alternatives where relevant.
5. Define the primary conversion.
6. List missing critical information.

## Output
- PROJECT.md draft
- Audience summary
- Problem/value summary
- Initial conversion hypothesis

## Question rule
Ask only for information that materially changes the website strategy.
