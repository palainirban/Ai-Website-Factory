# Workflow 03 — Design

## Input
Strategy and brand information.

## Actions
1. Select one primary design direction.
2. Define visual keywords.
3. Create color and typography system.
4. Define spacing and layout.
5. Define component rules.
6. Define image direction.
7. Define motion principles.
8. Review mobile and accessibility requirements.

## Output
- DESIGN.md
- Component inventory

## Rule
Do not imitate another brand directly. Borrow principles, not identity.
