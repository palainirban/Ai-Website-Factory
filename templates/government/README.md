# Government / Public Service Website Template

## Primary goals
- Help citizens complete tasks quickly
- Make information searchable and accessible
- Build clarity and trust

## Required considerations
- Accessibility-first
- Clear service navigation
- Notices and emergency information
- Search
- Bengali/English or required local languages
- Mobile-first forms

## Recommended homepage
Emergency/notice area → Service shortcuts → Search → Popular services → Announcements → Departments → Schemes → Contact/help
