# Restaurant Website Template

## Primary goals
- Increase reservations or orders
- Generate catering/event enquiries
- Build appetite and trust

## Recommended homepage
Hero → Signature dishes → Story → Menu preview → Catering → Gallery → Reviews → Location → FAQ → CTA

## Design direction
Food-first, warm, sensory, editorial. Use authentic food photography and avoid generic restaurant UI.

## Primary CTAs
- Order Now
- Reserve a Table
- Get Catering Quote
