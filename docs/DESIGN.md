## Hero rule
Every hero should answer:
1. What is this?
2. Who is it for?
3. Why should they care?
4. What should they do next?

## Mobile and accessibility
- Minimum 44×44px tap targets
- Keyboard navigation
- Visible focus states
- Sufficient contrast
- Semantic HTML
- Meaningful alt text
- Respect reduced motion

## AI anti-patterns
Do not:
- use random colors or spacing
- overuse gradients, glass effects or pills
- put everything in cards
- use excessive shadows
- mix unrelated font styles
- create generic “AI slop” UI

## Final AI instruction
Read this file before generating UI. Reuse existing tokens and components. Do not introduce a new visual language without a project reason.
